# Data access

None of the imaging data can be redistributed here. Each dataset is available from its source under that source's terms. `results/` contains derived outputs only, prepared as described below.

## Source datasets

| cohort | source | terms | used here |
|---|---|---|---|
| HCP, n = 238 | Human Connectome Project S1200, ConnectomeDB (<https://db.humanconnectome.org>) | HCP Open Access Data Use Terms; Restricted Data Use Terms for family structure, age and the alcohol-use measures | four resting-state runs of 1200 frames as released (preprocessed by the consortium), concatenated; diffusion data for in-house connectomes |
| ADNI-3, n = 49 | Alzheimer's Disease Neuroimaging Initiative (<https://adni.loni.usc.edu>) | ADNI Data Use Agreement | raw T1w, resting-state BOLD and diffusion, preprocessed in-house |
| Epilepsy (UNAM), n = 62 | OpenNeuro ds004469 (<https://openneuro.org/datasets/ds004469>) | as stated on OpenNeuro | raw BIDS data, preprocessed in-house |

Software used for preprocessing: fMRIPrep 23.2.3, QSIPrep 26.0.0 and FastSurfer 2.5.2 in Singularity containers; MRtrix3 3.0.8 for connectomes.

## What `results/` contains, and what it does not

- **Pseudonyms.** Every subject identifier was replaced before deposit: `Subject_###` for HCP, `ADNI_###` and `UNAM_###`, assigned in random order. The keys are held by the authors and are not in this repository. Rows are sorted by pseudonym.
- **HCP restricted variables.** No subject-level file contains age, family or twin-pair membership, zygosity or alcohol-use phenotype. The alcohol-use contrast is therefore deposited at group level only (`results/05_clinical/hcp_aud_group_comparison.csv`); the subject-level inputs to that analysis can be regenerated by anyone with HCP restricted access using `pipeline/01_operator_divergence/run_hcp_aud_batch.py`.
- **ADNI.** Subject-level files carry diagnostic group and scanner manufacturer only; age, diagnostic subtype and scanner model were removed.
- **Epilepsy cohort.** Exact age was removed; group, side and hippocampal volumes, which are part of the public dataset, are kept.
- **Not deposited:** timeseries, connectomes, effective-connectivity estimates and bootstrap ensembles.

## Re-running the pipeline

The scripts in `pipeline/` read data from paths given on the command line or in environment variables:

| variable | used by | meaning |
|---|---|---|
| `BASE`, `SIF_DIR`, `FS_LICENSE` | `run_adni_pipeline.sh`, `build_connectomes.sh` | ADNI data root, container directory, FreeSurfer license |
| `SUBJECT_LIST` | `run_adni_pipeline.sh`, `build_connectomes.sh` | text file with one ADNI subject ID per line |
| `TEST_SUBJECT` | `build_connectomes.sh` (test mode) | one subject ID for a trial run |
| `BASE`, `SIF_DIR`, `FS_LICENSE`, `UNAM_SUBJECTS` | `run_unam_pipeline.sh`, `run_unam_mriqc.sh` | epilepsy data root, containers, FreeSurfer license, space-separated subject list |
| `BNCS_ROOT` | `SCMatrixExtractor.py`, `02_ec_uncertainty/estimator_convergence/` | root of the site data, tools and outputs |
| `HCP_SUBJECTS`, `ADNI_SUBJECTS`, `UNAM_SUBJECTS`; `HCP_SUBJECT`, `ADNI_SUBJECT`, `UNAM_SUBJECT` | `02_ec_uncertainty/estimator_convergence/` | subjects to check, space-separated, or one subject |

Scripts that take arguments print their usage with `--help`; the model modules in `04_nonlinear_control/` are imported by the scripts that run them. Inputs are one regional timeseries (`.npy`) and one structural connectome (`.csv`) per subject, matched by file suffixes given as arguments (for example `--ts-suffix _native_timeseries.npy --sc-suffix _SC_SIFT2_410.csv`). `nctsens.loader` resolves the orientation of a timeseries by matching the known number of regions rather than by assuming more timepoints than regions, an assumption that fails for every ADNI recording.
